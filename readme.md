# Лабораторная работа
## Вариант №23 — Смешивание воды

### 1. Цель работы
Разработать программу на языке C++, которая вычисляет общий объём и температуру воды после смешивания трёх сосудов.

### 2. Условие задачи
В первом сосуде содержится V1 литров воды температурой t1, во втором — V2 литров воды температурой t2, в третьем — V3 литров воды температурой t3. Воду слили в один сосуд. Найти общий объём и температуру воды в этом сосуде.

### 3. Алгоритм решения
1. Ввести объёмы воды V1, V2, V3.
2. Ввести температуры t1, t2, t3.
3. Вычислить общий объём воды.
4. Вычислить итоговую температуру смеси.
5. Вывести результаты на экран.

### 4. Математические формулы

Общий объём:

`V = V1 + V2 + V3`

Итоговая температура:

`t = (V1*t1 + V2*t2 + V3*t3) / V`

### 5. Исходные данные

| Переменная | Значение |
|---|---:|
| V1 | 2 л |
| t1 | 20 °C |
| V2 | 3 л |
| t2 | 60 °C |
| V3 | 1 л |
| t3 | 80 °C |
